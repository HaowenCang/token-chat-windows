我有一个处理 CSV 文件的 Python 脚本，读取 50 万行数据大约需要 12 秒，有没有办法优化到 3 秒以内？目前用的是 csv 模块逐行读取。

▶ 💭 思考过程（2.1s）
用户需要优化 CSV 读取性能，从 12 秒降到 3 秒以内。当前使用 csv 模块逐行读取，主要瓶颈可能在：1) Python 解释器循环开销 2) 字符串解析 3) 未利用多核。可选方案：pandas read_csv（C 实现）、polars（Rust 实现）、多进程分块读取。推荐方案优先级：polars > pandas > 多进程。

有几种方案可以显著提速，按推荐顺序：

方案 1：使用 Polars（推荐）

比 pandas 快 5-10 倍，内存效率更高：

Python
import polars as pl # 读取 50 万行，通常 < 1 秒 df = pl.read_csv("data.csv") # 如果需要过滤，惰性模式更快 df = pl.scan_csv("data.csv").filter( pl.col("status") == "active" ).collect()

方案 2：Pandas + pyarrow 后端

Python
import pandas as pd df = pd.read_csv("data.csv", engine="pyarrow")

💡 如果数据结构已知，指定 dtype 可以再快 30%。避免使用 dtype=object。

Polers 方案不错，但如果数据里有混合编码（UTF-8 + GBK），它能处理吗？
14:34
🤖

Polars 对编码支持有限，主要处理 UTF-8。对于混合编码的场景，建议预处理：

Python
import polars as pl # 先用 Python 读取并统一编码 with open("data.csv", "rb") as f: raw = f.read() # 尝试 UTF-8，失败则 GBK try: text = raw.decode("utf-8") except UnicodeDecodeError: text = raw.decode("gbk") from io import StringIO df = pl.read_csv(StringIO(text))

或者用 chardet 库自动检测编码，准确率更高但会增加约 0.5s 延迟。
