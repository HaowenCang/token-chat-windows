请进行 UI bug 修复。项目主目录是 `token-chat/`，前端是 TypeScript + Vite，桌面端是 Tauri。请不要修改业务逻辑、Provider 数据结构、Token 统计计算、API 调用、SQLite 后端或路由逻辑；本次任务只修复前端 UI 组件、CSS 样式、弹层定位、表单布局和 Liquid Glass 视觉系统。

本次修复的核心目标是：恢复并规范 Liquid Glass 弹层系统。当前所有弹层被过度套用同一套“大圆角、强模糊、低密度”的玻璃样式，导致 tooltip、dropdown、date picker、modal 都变得像同一种大气泡。请将其改为“同一套 Liquid Glass 材质语言，不同组件 variant”的系统。

请重点检查并修改以下文件：

* `token-chat/src/liquid-glass.ts`
* `token-chat/src/liquid-glass.css`
* `token-chat/src/glass-system.css`
* `token-chat/src/custom-select.ts`
* `token-chat/src/custom-date-picker.ts`
* `token-chat/src/tooltip.ts`
* `token-chat/src/provider.ts`
* `token-chat/src/settings.ts`
* 如有必要，补充检查 `token-chat/src/styles.css`、`token-chat/src/unified-shell.css`、`token-chat/src/stats.ts`、`token-chat/src/chat.ts`

一、建立 Liquid Glass variant，而不是所有弹层共用一个外观

当前 `liquid-glass.ts` 已经有 `LiquidGlassLayer = 'dropdown' | 'popover' | 'tooltip' | 'modal' | 'dialog' | 'notice'`。请保留这种分层思想，但在 CSS 中进一步落实不同 variant 的尺寸、圆角、padding、blur、shadow 和 overflow 规则。

请至少区分以下 variant：

```ts
type LiquidGlassLayer =
  | 'dropdown'
  | 'date-picker'
  | 'tooltip'
  | 'popover'
  | 'modal'
  | 'dialog'
  | 'notice';
```

如果不想改 TypeScript 类型，也可以继续使用 `'popover'`，但必须给 date picker 独立 class，例如 `.glass-date-popover`，且不能继承 `.glass-dropdown` 的滚动规则。

请在 `liquid-glass.css` 中拆分：

```css
.liquid-glass--tooltip
.liquid-glass--dropdown
.liquid-glass--date-picker
.liquid-glass--popover
.liquid-glass--modal
.liquid-glass--dialog
```

不要再让 tooltip、dropdown、date picker、modal 共享完全相同的 `border-radius`、`padding`、`overflow-y:auto`、`max-height` 和 `box-shadow`。

建议 token：

```css
:root {
  --glass-radius-tooltip: 16px;
  --glass-radius-dropdown: 18px;
  --glass-radius-date-picker: 20px;
  --glass-radius-modal: 28px;

  --glass-blur-tooltip: 18px;
  --glass-blur-dropdown: 22px;
  --glass-blur-date-picker: 24px;
  --glass-blur-modal: 28px;

  --glass-shadow-tooltip: 0 10px 28px rgba(31, 35, 50, 0.14);
  --glass-shadow-dropdown: 0 14px 36px rgba(31, 35, 50, 0.16);
  --glass-shadow-modal: 0 28px 80px rgba(31, 35, 50, 0.24);
}
```

二、修复 `custom-date-picker.ts` 的日期选择器滚动条 bug

当前日期选择器创建 popover 时使用了类似：

```ts
popover.className = liquidGlassClasses('popover', 'glass-date-popover glass-dropdown');
```

请修复这一点。日期选择器不应该带 `glass-dropdown` class，因为 dropdown 的 `overflow-y:auto`、`max-height` 和列表密度会污染 calendar 面板，导致日期面板内部出现垂直滚动条。

请改为类似：

```ts
popover.className = liquidGlassClasses('date-picker', 'glass-date-popover');
```

如果不改 `LiquidGlassLayer` 类型，则至少改为：

```ts
popover.className = liquidGlassClasses('popover', 'glass-date-popover');
```

并确保 `.glass-date-popover` 不匹配 `.glass-dropdown` 的 CSS 选择器。

日期选择器修复要求：

1. 单月日期选择器不得出现内部垂直滚动条。
2. popover 高度应由内容自然撑开，不继承 dropdown 的 `max-height` 或 `overflow-y:auto`。
3. `.glass-date-popover` 应设置：

   * `overflow: visible` 或 `overflow: hidden`，但不能 `overflow-y:auto`
   * 合理固定宽度，例如 `320px`
   * 自适应窗口边界
   * 月份标题、星期行、42 个日期格、底部“清除 / 今天”按钮完整显示
4. calendar grid 使用固定 7 列布局。
5. 日期格尺寸保持紧凑，不要像 modal 一样大。
6. 底部按钮区与日期网格之间只保留轻量分割线。
7. 今天、选中日期、range start、range end、range middle、hover 状态要清晰但克制。
8. date picker 必须通过 portal 渲染到顶层，避免被父容器裁切。

请重点检查：

```css
.custom-select-menu.liquid-glass,
.glass-dropdown.liquid-glass,
.token-trend-model-menu.liquid-glass
```

这一类选择器是否把 `.glass-date-popover` 也包含进去了。日期选择器必须从 dropdown 样式中拆出来。

三、修复 dropdown 过大、选中描边过强的问题

请修改 `custom-select.ts` 和相关 CSS。

当前普通下拉菜单，例如模型选择、货币选择、语言选择、主题选择，不应该变成大尺寸玻璃弹窗。dropdown 应当是紧凑列表，而不是 modal。

要求：

1. `custom-select-menu` 默认宽度应与 trigger 对齐。
2. `positionMenu()` 中保留 `matchAnchorWidth` 或等价逻辑，不要让 dropdown 任意变宽。
3. panel padding 控制在 `6px - 8px`。
4. option 行高控制在 `36px - 42px`。
5. 圆角控制在 `16px - 18px`，不要使用 modal 级别大圆角。
6. 选中项只使用淡紫色背景或左侧细指示条，不要使用厚重紫色描边。
7. `focus-visible` 只在键盘导航时出现，不要把 selected 状态渲染成强烈 focus ring。
8. 4-8 项的下拉菜单不得出现滚动条。
9. 只有当选项超出可视区域时，才允许 `max-height` 和细滚动条。
10. dropdown 仍然使用 Liquid Glass 材质，但密度必须接近普通菜单。

请检查并修复模型选择下拉框、货币选择下拉框、语言选择下拉框、主题选择下拉框。

四、修复 tooltip 过大、过重的问题

请修改 `tooltip.ts` 与 `liquid-glass.css` 中 `.data-tooltip-bubble`、`.glass-tooltip`、`.data-tooltip-row` 等样式。

当前 Token 监控图表 tooltip 过大、过白、圆角过大、文字过粗，遮挡图表和下方 Provider/模型信息。Tooltip 应该是 compact variant，不应该像 modal。

要求：

1. tooltip 最大宽度控制在 `240px - 280px`。
2. padding 控制在 `10px - 14px`。
3. 圆角控制在 `14px - 16px`。
4. 标题可以半粗，普通 label 不要过粗。
5. 数值可以 `font-weight: 600`，不要所有文字都加粗。
6. label、彩色圆点、数值使用 grid 对齐。
7. tooltip 应贴近数据点，并自动避让右侧栏边界。
8. tooltip 不应遮挡过多图表或下方模型信息。
9. tooltip 不得被 Token 监控侧栏裁切。
10. 如果使用 SVG filter、blur、displacement 模拟折射，绝对不能作用到 `.liquid-glass__content`，文字必须保持清晰。

建议结构保持 `tooltip.ts` 现有的 `ensureTooltip()` 和 `liquidGlassLayers()`，但 CSS 必须改为 tooltip compact variant，而不是继承通用大玻璃面板。

七、修复 Liquid Glass 视觉过强的问题

保留边缘折射、高光、内阴影和玻璃感，但不要让所有弹窗都像大气泡。请按 variant 调整强度：

Tooltip:

* 最轻、最紧凑
* 边缘高光轻
* 阴影小
* 文字最清晰

Dropdown:

* 紧凑菜单
* 与 trigger 对齐
* 轻微玻璃背景
* 无夸张折射

Date picker:

* 中等玻璃面板
* 不滚动
* 日历网格清晰

Modal:

* 最稳定、最可读
* 背景更实
* blur 可存在，但不要影响表单阅读

不要把 `.liquid-glass::before`、`.liquid-glass::after` 的强高光和强 caustic 效果无差别套到所有组件。如果需要，给不同 variant 调整 opacity：

```css
.liquid-glass--tooltip::before { opacity: .35; }
.liquid-glass--dropdown::before { opacity: .42; }
.liquid-glass--date-picker::before { opacity: .45; }
.liquid-glass--modal::before { opacity: .25; }
```

八、禁止 filter 影响文字内容

请检查 `liquid-glass.css` 和所有相关组件。任何 `filter: blur()`、SVG displacement、backdrop blur、mask、mix-blend-mode 都不能影响文本内容层。

正确分层：

```html
<div class="liquid-glass liquid-glass--tooltip">
  <span class="liquid-glass__refract-layer"></span>
  <span class="liquid-glass__rim"></span>
  <div class="liquid-glass__content">
    <!-- 文字、按钮、输入框等必须保持 sharp -->
  </div>
</div>
```

`.liquid-glass__content` 必须：

```css
filter: none !important;
backdrop-filter: none !important;
position: relative;
z-index: 2;
```
